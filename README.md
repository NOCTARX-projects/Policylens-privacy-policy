##  About PolicyLens

PolicyLens is a browser extension designed to help users **analyze and understand privacy policies and terms of service** in a simple and clear way.

It provides:

*  Instant privacy risk scores
*  Simplified summaries of policies
*  Detection of potentially risky clauses
*  Insights into data collection and sharing practices

---

##  Privacy-First Approach

PolicyLens is built with a strict **privacy-first philosophy**:

* ❌ No personal data collection
* ❌ No tracking or analytics
* ❌ No ads or monetization of user data
* ✔ All analysis is performed locally in the browser
* ✔ User data never leaves the device
